# vireon-publications

The goal of VIREON is to end the publication of static PDFs.

`vireon-publications` is a registry of YAML execution manifests. When an author publishes a paper utilizing VIREON, they submit their execution DAG manifest to this repository. Peer reviewers can clone this repository, run `vireon reproduce paper_id`, and immediately generate the exact `IEvidence` bundle and statistical plots cited in the paper.
