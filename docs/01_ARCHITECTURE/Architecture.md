# System Architecture

VIREON is structured as a Native Neuroscience Evidence Engine. It shifts the paradigm from ad-hoc script execution to formalized, cryptographically verifiable scientific workflows. The system is split into independent bounded contexts: Core (Execution), Models (Generative Data & Hardware Twins), Validation (Statistical Rigor), and Evidence (Reporting & Provenance).

## Phase E Capabilities
In Phase E, this architectural component is fully active. The execution model supports authentic biological datasets alongside Digital Twins, generating EvidenceBundles that map back to originating literature.
