# Using the Evidence Graph

VIREON treats scientific validation as a semantic network. Every `EvidenceBundle` generated by a Campaign becomes a node in the **Evidence Graph**.

## The Operational Envelope

When you query the Evidence Graph, you aren't just looking at isolated runs. You are constructing an **Operational Envelope**. 

By evaluating how an algorithm performs across a Cartesian sweep of conditions (e.g., varying Signal-to-Noise ratios, varying channel dropout rates, multiple patient datasets), the Evidence Graph maps the precise boundary where the algorithm degrades.

Instead of claiming *"Our method is robust,"* you can query the graph to objectively state:
> *"Our method maintains CCC > 0.85 provided SNR > 5dB, line noise < 20uV, and missing data bursts < 500ms."*

This shifts the paradigm of neuroscience tooling from **Exploratory Signal Processing** to **Rigorous Scientific Infrastructure**.
